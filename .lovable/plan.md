# Smart Attendance frontend prototype

## What I’ll build
- A polished Academic Slate interface with the selected blue academic palette, Space Grotesk headings, Inter body text, rounded cards, and restrained shadows.
- Eleven responsive screens: landing, login, signup, admin dashboard, faculty dashboard, student dashboard, attendance, classes, student records, analytics/reports, and profile/settings.
- A shared navigation system with desktop sidebar, compact mobile navigation, consistent headers, buttons, filters, forms, status labels, cards, charts, and tables.
- Clickable navigation and visual interactions using realistic mock data only.

## Structure
- Public landing and account screens will use the same brand system as the app.
- Dashboard and management screens will share one responsive application shell.
- Each named screen will have its own URL and page-specific social/search metadata.

## Technical details
- React and TanStack Router routes, Tailwind CSS v4 semantic tokens, existing button/form components, Lucide icons, and Recharts where useful.
- No backend, APIs, database, authentication, ML, face recognition, QR validation, or persistent attendance logic.
- Validate the main navigation flow and key layouts at desktop and mobile sizes, then resolve any preview errors.
